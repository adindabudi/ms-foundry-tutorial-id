# Support

This repository provides tutorial content and sample data. It is not an official Microsoft support channel.

Use GitHub issues for:

- Broken links.
- Build failures.
- Accessibility bugs.
- Incorrect tutorial steps.
- Outdated Microsoft Foundry feature status.

Use Microsoft Learn, Azure support, or your tenant administrator for:

- Azure subscription access.
- Microsoft 365 admin approval.
- Tenant policy changes.
- Production support incidents.
