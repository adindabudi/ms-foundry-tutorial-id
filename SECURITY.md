# Security Policy

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub issues.

Use GitHub private vulnerability reporting for this repository. If private vulnerability reporting is not enabled, ask the repository owner to enable it before sharing exploit details.

Include:

- Affected file or page.
- Steps to reproduce.
- Impact.
- Whether secrets, tenant identifiers, screenshots, or user data are exposed.

## Content Safety

This repository must not contain real secrets, real tenant identifiers, real subscription IDs, user emails, private customer data, or unsanitized portal screenshots.
