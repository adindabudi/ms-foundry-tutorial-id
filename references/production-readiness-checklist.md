# Production Readiness Checklist

Use this checklist before a pilot.

- [ ] Agent answers key prompts in Bahasa Indonesia.
- [ ] Playground answers cite expected source documents.
- [ ] Out-of-scope prompts are refused or redirected.
- [ ] Similar policy terms are distinguished correctly.
- [ ] Trace or run detail was checked when available.
- [ ] Active version is pinned before pilot.
- [ ] Teams/M365 publish status and limitations are explained to stakeholders.
- [ ] Screenshots and validation logs contain no private tenant data.
