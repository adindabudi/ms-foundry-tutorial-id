# Governance

This repository is maintained as an open tutorial project for Indonesian Microsoft Foundry learning content.

## Maintainer Responsibilities

- Keep feature-readiness statements sourced and current.
- Review screenshots for private data before merge.
- Keep generated sample data clearly fictional.
- Require successful build and accessibility checks for public-facing changes.
- Prefer small, reviewable pull requests.

## Decision Rules

- Accuracy beats speed for Microsoft feature status.
- Portal-first Foundry 101 content must not introduce code-first steps.
- Tenant-dependent steps must include a fallback path.
- Generated assets must preserve source files or prompts when practical.
